# AutoTyper video

The demo video, app icon and GitHub social image for AutoTyper, made with [Remotion](https://www.remotion.dev).

- `Demo` is the 35 second walkthrough (1920x1080).
- `Icon` is the 1024px app icon, copied to `build/icon.png`.
- `Social` is the 1280x640 GitHub preview image.

```bash
npm install
npx remotion studio
```

Screenshots in `public/` come from `scripts/screenshots.mjs` in the main project.
